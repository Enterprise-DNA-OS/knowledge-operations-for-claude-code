# review-queue

Read CLAUDE.md first. Plan the editorial review queue.

Run `node scripts/knowledge.mjs review-queue`. Replace placeholders with the operator's supplied values; quote names and text as single arguments. Add `--json` to read structured results. Run `help` if any argument is unclear.

Read the article and its history before any change. Never invent a name, evidence, review decision, date or resolution. If a match is ambiguous, show the candidate IDs. For writes, use the operator's actor label and confirm the intended record from the read result. An actor label is not authenticated identity.

Present the records in plain language, with IDs for follow-up. State missing information explicitly.
