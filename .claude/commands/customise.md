# Customise
Read CLAUDE.md and inspect the current schema and CLI first. Translate the operator's request into a concrete field or rule change. Add a numbered SQL migration, never edit an applied migration. Update validation, CLI, seed, reports and relevant command recipes together. Add a test for the real business rule, run npm test, then apply npm run migrate to the intended database. Back up real records with export before applying a change. Destructive changes need the operator's explicit approval. Keep one CLI and no front end.
